แผนรายสัปดาห์ (ช่วงที่ 1)

แผนรายเดือน

โปรเจกต์ที่ควรทำ (8 ชิ้น)

ทำตามลำดับ ติ๊กทุกขั้นตอนถึงนับว่าจบโปรเจกต์ และอัปทุกชิ้นขึ้น GitHub พร้อม README

แหล่งฝึกโจทย์และข้อสอบ Python

ทำวันละ 3–5 ข้อ ลองเองก่อนดูเฉลย และจดข้อที่ผิดลงสมุด

ช่วงที่ 1 (ตอนนี้): เริ่มต้น

  • CodingBat: โจทย์สั้น กดตรวจคำตอบได้ทันที แบ่งหมวด if, loop, string, list
  • W3Schools Python Exercises: แบบฝึกหัดและควิซตามหัวข้อ
  • PYnative Python Exercises: แยกตามหัวข้อ มีเฉลย

ช่วงที่ 1–2: ระดับถัดไป

  • HackerRank (Python): มีเส้นทางสำหรับมือใหม่ ระบบตรวจให้
  • Exercism (Python track): ฟรี โจทย์เรียงตามระดับ

ช่วงที่ 2 เป็นต้นไป: อัลกอริทึม

  • Codewars: เริ่มที่ระดับ 8 kyu
  • LeetCode: เริ่มที่ระดับ Easy

สำหรับสอบวิชาที่เรียน

  • ข้อสอบเก่าจากอาจารย์หรือรุ่นพี่ ตรงกับข้อสอบจริงที่สุด
  • โจทย์ท้ายสไลด์ของทุกสัปดาห์ (Week 12 มี 5 ข้อสำหรับเขียนฟังก์ชัน และ 5 ข้อสำหรับเรียกใช้ฟังก์ชัน)

แหล่งเรียนและหนังสือ

  • Python: Automate the Boring Stuff with Python (อ่านฟรีออนไลน์)
  • คณิต: Khan Academy (พีชคณิต), 3Blue1Brown (Linear Algebra และ Calculus)
  • อัลกอริทึม: Grokking Algorithms
  • Machine Learning: Machine Learning Specialization ของ Andrew Ng, หนังสือ Hands-On Machine Learning ของ Aurélien Géron
  • Deep Learning: fast.ai Practical Deep Learning, PyTorch Tutorials

กติกา 3 ข้อ

  • ติดแล้วลองเองก่อน 10 นาที แล้วค่อยถามหรือดูเฉลย
  • จดข้อที่ผิดบ่อยไว้ในสมุดเล่มเดียว
  • พลาดหนึ่งวันไม่เป็นไร แต่ห้ามพลาดสองวันติด

สมุดข้อที่ผิดบ่อย

จดข้อที่ผิดพร้อมสาเหตุ (บันทึกอัตโนมัติ) ทบทวนทุกวันอาทิตย์
